# Acton Citizens' Band

A welcoming home for the Acton Citizens' Band, bringing people together through
music in Acton, Ontario, since 1872. The website introduces the band, welcomes
new musicians and learners, and helps our community discover upcoming concerts,
parades, and other performances.

[Visit actoncitizensband.ca](https://actoncitizensband.ca)

The site pairs historic band photographs with interactive 3D instruments,
light and dark themes, and calendar subscriptions that make it easy to keep
up with our events.

## Built with

- **React and TypeScript** for the interface, with **SCSS** for responsive styling.
- **Webpack** to bundle the application and prepare assets for production.
- **Three.js** for instruments that respond to pointer movement and device tilt.
- **Firebase Hosting** to serve the website, with **Cloud Firestore** providing
  event listings and feature flags.
- **GitHub Actions** for automated checks, preview builds, and deployment.
