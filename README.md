# Acton Citizens' Band

A welcoming home for the Acton Citizens' Band, bringing people together through
music in Acton, Ontario, since 1872. Discover the band, learn an instrument, join
our musicians, and find upcoming concerts, parades, and community performances.

[Visit actoncitizensband.ca](https://actoncitizensband.ca)

## Built with

- **React and TypeScript** for the interface, with **SCSS** for responsive styling.
- **Webpack** to bundle the application and prepare assets for production.
- **Three.js** for instruments that respond to pointer movement.
- **Firebase Hosting** to serve the website, with **Google Cloud Firestore** providing event listings and feature flags.
- **GitHub Actions** for automated checks, preview builds, and deployment.
- **Search and social metadata**, structured data, and a sitemap to help services understand and share the website.
- **Responsive images, lazy loading, and cache-friendly assets** to reduce downloads and improve loading performance.
